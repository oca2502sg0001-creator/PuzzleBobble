Shooterクラス
プレイヤーが操作する発射台のクラス

角度管理 (angle): バブルを打ち出す方向をラジアンで保持しています。初期値の DX_PI_F / 2.0f は真上を指します。

操作 (Update): Aキーで反時計回り（角度増加）、Dキーで時計回り（角度減少）に回転します。

制限 (GameConfig::Clamp): 砲台が真横や下を向かないように、角度を一定の範囲（0.2〜π-0.2）に制限しています。

描画 (Draw): cosf と sinf を使い、現在の角度に合わせて「ガイド線」を一本描画します。


Bulletクラス（発射される弾）
発射されたバブルの移動と衝突の挙動を管理します。

発射: 砲台の角度と色を受け取り、速度ベクトル（vel）を計算します。

vel.x = cosf(angle) * Speed

vel.y = -sinf(angle) * Speed

反射ロジック: Update 関数内で左右の壁に当たったかどうかを判定し、当たった場合は vel.x を反転（-1.0f を掛ける）させることで「反射」を表現しています。

無効化: 画面外（上下）に出た場合は active = false になり、再発射が可能になります。

スペースキーでのトリガーについて
int currentSpaceState = CheckHitKey(KEY_INPUT_SPACE);
if (currentSpaceState && !lastSpaceState && !bullet.IsActive()) { ... }
lastSpaceState = currentSpaceState;

衝突検知: bm.CheckCollision でバブルに当たったか判定しています

バブル設置: bm.SetBubble で、弾が止まった位置にバブルを固定します。

連鎖処理: bm.ProcessChain を呼び出し、同じ色のバブルが3つ以上並んだかを確認して削除します。

bullets.push_back(newBullet);　動的配列の一番後ろに新しい要素を追加するコードです

浮いた玉の落下について：起点判定： 玉が消えた後、天井（1行目）から「色を問わず」隣接する玉を数珠つなぎに全て調べる。

			 孤立除去： スキャンで誰とも繋がらなかった（天井へのルートが断絶した）玉の塊をすべて落下させる。


浮いた玉の落下アニメーションについて：
	浮いた玉を即削除するのではなく、「落下中専用オブジェクト」という別のオブジェクトとして管理しています。

	落下開始時に AddFallingBubble() を呼び出し、fallingBubbles に追加します。落下状態にしたのと同時に盤面から削除することで、通常の当たり判定から除外します。
	毎フレーム重力と回転を加えてあげることで、自然な落下の挙動に見えるようにしています。
